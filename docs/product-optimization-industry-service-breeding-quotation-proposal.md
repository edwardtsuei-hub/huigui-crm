# 其他行业报价页优化方案

## 状态

- 当前状态：`正式最小改动 V1 已接入`
- 当前相关正式页网址：
  - `http://127.0.0.1:3202/solutions`
  - `http://127.0.0.1:3202/solutions/industry/new`
  - `http://127.0.0.1:3202/solutions/service/new`
  - `http://127.0.0.1:3202/solutions/breeding/new`

## 当前确认范围

- 农业方案：
  - `不动`
- 当前侧边里的两个次级入口：
  - `农业方案`
  - `其他行业`
  - `保留，不拆更多入口`
- 当前只处理 `其他行业` 报价页里的两个问题：
  - 行业下拉要补齐大类选项
  - 产品下拉要正常带出已上传产品

## 当前代码与数据判断

- 当前 `其他行业` 页实际复用：
  - `apps/web/app/(dashboard)/quotes/general/page.tsx`
- 当前页面会同时加载三份数据：
  - `客户`
  - `产品`
  - `行业`
- 这三份数据现在通过同一个 `Promise.all(...)` 一起取。
- 只要其中一个接口失败，前端就不会把行业和产品选项渲染出来。
- 正式数据库里当前已确认：
  - 行业大类已存在：
    - `农业`
    - `工业`
    - `服务业`
    - `养殖业`
  - 产品已存在且启用：
    - `GA 土壤激活剂`
    - `GB 叶面营养剂`
- 所以“下拉没有内容”并不是因为 GA / GB 没有入库，而更像是前端加载链路把可用数据一起卡掉了。

## 建议的第一版方案

### 1. 保持入口结构不变

- 保留当前：
  - `农业方案`
  - `其他行业`
- 不拆成独立的 `服务报价 / 养殖报价 / 工业报价` 页面入口。

### 2. 只在 `其他行业` 页补齐行业大类

- 行业下拉里补上：
  - `工业`
  - `服务业`
  - `养殖业`
- 农业不放进这个“其他行业”专页的手动主选项里。
- `默认沿用客户行业` 继续保留。

### 3. 产品下拉必须正常带出已上传产品

- GA / GB 已经在正式产品表里，且状态为 `ENABLED`。
- 第一版不做复杂行业筛选。
- 先保证只要是当前可报价产品，就能在产品下拉中看到。
- 也就是先解决“有数据但没显示”的问题。

### 4. 先修加载链路，不做大改 UI

- 当前页不是“产品没关联”，而更可能是：
  - 页面把 `客户 / 产品 / 行业` 绑成一次并发请求
  - 其中任意一个失败，就导致剩下两项也不显示
- 第一版建议改成：
  - 分开加载客户、产品、行业
  - 至少保证 `行业` 和 `产品` 不会因为客户接口异常而一起空掉

## 我建议第一版先做到的内容

- 农业方案完全不动
- `其他行业` 页行业下拉补齐：
  - `工业`
  - `服务业`
  - `养殖业`
- `其他行业` 页产品下拉正常显示已启用产品
- 修正下拉加载逻辑，避免一个接口报错把全部选项清空

## 我建议第一版先不做的内容

- 不改农业方案页
- 不拆新的侧边栏入口
- 不拆新的独立报价页面
- 不做行业专属审批或模板差异
- 不做产品按行业强筛，先保证能正常显示

## 推荐实施顺序

1. 先修 `其他行业` 页的数据加载方式
2. 补齐行业下拉大类选项
3. 验证 GA / GB 在产品下拉中正常可见
4. 回写文档与验收说明
