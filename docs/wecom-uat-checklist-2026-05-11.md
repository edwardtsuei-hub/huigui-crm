# 2026-05-11 企业微信功能 UAT 验收清单

## 使用方式

- 面向业务验收、产品验收、上线复核。
- 建议在生产环境 `https://crm.hui-health.com` 跑一遍。
- 每一项完成后在复选框中打勾，并在「实际结果」处补一句结论。
- 如果出现失败项，先到 `/management/wecom` 查看同步、通知、回调记录，再按 runbook 排错。

## 验收范围

本清单覆盖：

- 企业微信扫码登录
- CRM 账号与企业微信成员绑定
- 管理员企业微信成员绑定 / 解绑 / 测试通知
- 企业微信消息通知与跳转
- CRM 日程同步到企业微信日历
- 日历同步失败重试与自动巡检
- 企业微信回调日志
- 权限限制与安全边界

不覆盖：

- 企业微信通讯录组织架构完整同步
- 企业微信审批流
- 企业微信外部联系人
- 多企业、多 CorpID 场景
