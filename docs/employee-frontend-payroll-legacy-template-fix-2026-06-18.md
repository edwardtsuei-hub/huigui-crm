# 员工端薪资旧版工资表兼容修复（2026-06-18）

## 问题

用户在灰度入口上传 `/Users/i-datsuei/Downloads/在觉乐工资表2026-05-修正版.xlsx` 后，页面提示：

- 缺少表头：`应发`
- 缺少表头：`实发`
- 缺少表头：`员工ID/用户ID/企业微信账号/登录账号/系统账号`
- 多行金额异常与缺少员工身份

实际 Excel 工作表为 `工资`，表头是：

```text
序号, 姓名, 基础工资, 提成, 奖金, 应付工资, 社保扣费, 公积金, 个税, 实发工资, 备注
```

这是旧版工资表，不是系统原先要求的标准薪资条上传模板。

## 修复

- 兼容旧版金额表头：
  - `基础工资` -> 系统 `应发`
  - `奖金` -> 系统 `分润`
  - `社保扣费 + 公积金 + 个税` -> 系统 `扣款`
  - `实发工资` -> 系统 `实发`
  - `应付工资` 用于校验基础工资、提成、奖金合计
- 自动过滤 `合计 / 总计 / 小计` 行，避免把合计行导成 `未命名` 员工。
- 没有身份列的旧版工资表允许灰度预览：
  - `觉心` 映射到 `JiaoXin`
  - `程素风` 映射到 `ChengCheng`（程程）
  - `马立新 / 燕子` 映射到 `Malixin`
  - `高美娟` 映射到 `huixin`（慧心）
  - `子青` 映射到 `0da36207717ef93360b0e5115daba6ab`
  - 未匹配身份的人员按姓名生成手工身份，可入库但不会收到企业微信通知。
