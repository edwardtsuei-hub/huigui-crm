# 档案中心自动归档与业务回链 V1（2026-05-11）

## 结论

- 档案中心 V1 已从“文件库”推进到“可识别业务来源的档案中心”。
- 本轮不新增数据表，不做重型版本历史审批，只复用 `FileRecord.businessType/businessId` 与 `relatedType/relatedId` 打通最小闭环。

## 已实现

1. 上传自动归档
   - 上传时如果传入业务类型和业务 ID，后端会自动识别：
     - `CUSTOMER`
     - `QUOTATION`
     - `SALES_ORDER`
     - `INSPECTION_ORDER`
     - `PRODUCT`
     - `CONTRACT`
     - `PROJECT`
   - 未手动选择资料夹时，系统自动建立两层资料夹：
     - 业务根目录，如 `报价档案`
     - 业务对象目录，如 `Q-20260511-001`

2. 自动补分类与归档状态
   - 报价文件默认归入 `报价附件`
   - 订单文件默认归入 `订单附件`
   - 检测文件默认归入 `检测附件`
   - 产品文件默认归入 `产品资料`
   - 带业务关联的文件默认标记为 `ARCHIVED / 已归档`

3. 同名版本链
   - 同一业务对象下，如果上传同名文件，系统会接入已有 `versionGroupId`，形成新版本。
   - 避免业务附件变成孤立重复文件。

4. 业务回链
   - 后端序列化 `relatedEntity.label/name/href`
   - 前端右侧详情支持 `前往业务`
   - 文件列表摘要会显示业务对象信息

5. 前端上传入口
   - 上传抽屉支持选择业务类型
   - 支持填写业务对象 ID
   - 文件分类可保留“自动判断”

## 验收方式

1. 在档案中心上传一个文件，选择业务类型为 `报价`，填入正式报价 ID。
2. 上传完成后确认：
   - 文件进入 `报价档案 / 报价编号` 目录
   - 状态显示 `已归档`
   - 分类显示 `报价附件`
   - 右侧详情显示关联报价
   - 点击 `前往业务` 可以跳回报价详情
3. 在同一报价下再次上传同名文件，确认版本号递增，而不是形成孤立重复文件。
