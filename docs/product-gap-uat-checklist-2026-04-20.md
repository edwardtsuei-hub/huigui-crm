## 使用方式

- 这份清单面向产品、测试、业务验收。
- 每次迭代只勾选本轮交付范围，不必一次跑完整套。
- 建议每个场景至少覆盖：
  - 超级管理员
  - 普通业务角色

## A. 全局搜索

- [ ] 输入客户名，可返回客户结果并进入客户详情。
- [ ] 输入报价单号，可返回报价结果并进入报价详情。
- [ ] 输入订单号，可返回订单结果并进入订单详情。
- [ ] 输入检测单号，可返回检测结果并进入检测详情。
- [ ] 输入成员名，可返回成员结果并进入成员页或详情。
- [ ] 结果按对象类型分组展示，不与工作台入口混淆。
- [ ] 无结果时，提示语义为“未找到业务对象”。
- [ ] 普通角色搜索结果只返回其有权限查看的对象。

## B. 报价转订单

- [ ] 从报价详情点击“转为订单”后，不直接落库，而是进入确认层。
- [ ] 默认带出报价明细和客户信息。
- [ ] 缺收货信息时不可提交。
- [ ] 缺仓库或关键履约字段时不可提交。
- [ ] 提交成功后自动进入订单详情。
- [ ] 已转单报价再次进入时显示“查看订单”。
- [ ] 同一报价不会重复转出第二张订单。

## C. 检测待补关联

- [ ] 检测工作台可筛出全部待补关联记录。
- [ ] 支持多选检测记录。
- [ ] 支持批量补客户。
- [ ] 支持批量补产品。
- [ ] 批量提交后，首页提醒数即时变化。
- [ ] 已完成关联的记录不再出现在待补关联队列。
- [ ] 自动匹配不确定时，系统要求人工确认。
- [ ] 无编辑权限账号不可执行批量修改。

## D. 报价中心批量处理

- [ ] 报价列表支持多选。
- [ ] 支持批量导出。
- [ ] 支持批量发起审批。
- [ ] 支持批量标记已发送或同类推进动作。
- [ ] 批量结果返回成功 / 失败明细。
- [ ] 刷新页面后，已保存筛选视图仍可使用。

## E. 订单中心批量处理

- [ ] 订单列表支持多选。
- [ ] 支持批量催收。
- [ ] 支持批量进入发货准备。
- [ ] 支持批量更新状态。
- [ ] 操作后列表数据即时刷新。
- [ ] 普通角色只能处理自己可见订单。

## F. 行业 / 服务 / 养殖报价

- [ ] 从行业报价入口进入后，标题和说明体现行业报价语义。
- [ ] 从服务报价入口进入后，标题和说明体现服务报价语义。
- [ ] 从养殖报价入口进入后，标题和说明体现养殖报价语义。
- [ ] 三类报价默认产品范围有差异，不是完全同一批数据。
- [ ] 三类报价导出结果能看出类型差异。

## G. 客户池治理

- [ ] 可识别高疑似重复客户。
- [ ] 支持发起客户合并。
- [ ] 可查看超时未跟进客户队列。
- [ ] 可查看高意向客户队列。
- [ ] 管理员可查看按负责人分组的客户负载。

## H. 产品解析

- [ ] 解析结果展示字段置信度。
- [ ] 解析结果展示来源说明。
- [ ] 冲突字段不会静默覆盖原值。
- [ ] 支持连续处理多条产品录入任务。
- [ ] 支持进入待确认队列后再逐条确认。

## I. 档案自动归档

- [ ] 从报价上传的文件自动挂到报价对象下。
- [ ] 从订单上传的文件自动挂到订单对象下。
- [ ] 从检测上传的文件自动挂到检测对象下。
- [ ] 对应业务详情页可以直接看到关联档案。
- [ ] 上传同名新版文件时，形成版本链而不是孤立文件。
- [ ] 待审核文件可进入专门队列。

## J. 工作管理团队闭环

- [ ] 管理者可一键提醒未提交周报成员。
- [ ] 管理者可一键提醒未提交月目标成员。
- [ ] 团队视角能看见谁未提交、谁风险高、谁内容为空。
- [ ] 周报和月目标可直接派生提醒或待办。

## K. 通知与日程

- [ ] 通知支持批量已读。
- [ ] 通知支持转待办。
- [ ] 通知支持稍后提醒。
- [ ] 日程支持从当前事项直接分派给他人。
- [ ] 处理通知 / 日程后，来源对象状态同步更新。

## L. 角色权限与管理安全

- [ ] 修改角色权限前可看到 diff。
- [ ] 修改角色权限前可看到影响面预览。
- [ ] 支持复制现有角色。
- [ ] 保存前需要二次确认高风险权限变更。
- [ ] 普通管理员不可越权修改超级管理员级权限。

## M. 回归验证

- [ ] 首页快捷创建仍可正常使用。
- [ ] 首页通知抽屉仍可打开并跳转。
- [ ] 客户详情 → 新建报价仍能自动带入客户。
- [ ] 报价详情 → 查看客户 / 查看订单跳转正常。
- [ ] 订单详情的收款、发货入口仍正常。
- [ ] 检测详情的附件上传和返回链路仍正常。
- [ ] 档案中心基础上传、建资料夹、刷新清单仍正常。
